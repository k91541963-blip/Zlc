# Zlc

Nova Launcher (Zalith Launcher 2 fork) APK mirror.

- `apk/NovaLauncher-arm64-debug.apk` is updated automatically by GitHub Actions
  from the latest successful build of
  [k91541963-blip/ZalithLauncher2](https://github.com/k91541963-blip/ZalithLauncher2).
- ARM64 (arm64-v8a) debug build.
